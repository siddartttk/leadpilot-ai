# Potential customization services

These are scope descriptions, not published pricing or outcome guarantees. Each engagement needs discovery and a separate estimate.

| Offering | Customization work | Client inputs |
| --- | --- | --- |
| Lead capture installation | Workspace-specific capture endpoint, embed policy, consent text, anti-abuse controls, and source mapping | Website access, intake fields, privacy requirements |
| CRM setup | Service catalog, pipeline definitions, assignments, data migration, permissions, and user onboarding | Existing records, team roles, stage definitions |
| Assisted qualification | Confirmed budget bands, service rules, factor weights, extraction review process, and model evaluation | Qualification criteria, representative de-identified inquiries |
| Sales analytics | Agreed metric definitions, historical milestone tracking, reporting periods, and source attribution | Business questions and event/data quality requirements |
| Follow-up workflow | Task ownership, due-date rules, escalation policy, and in-app reminders | Team process and consent boundaries |
| Custom integration | Secure scoped connection to the client's forms, CRM, calendar, or email drafting system | Approved API/OAuth access and explicit data-processing authorization |

Production work includes PostgreSQL verification, hosting, backups, monitoring, account lifecycle, reviewed legal policies, and deployment security. Any future external sending requires explicit human approval and a separate consent/audit design. No financial return or conversion improvement is guaranteed.
