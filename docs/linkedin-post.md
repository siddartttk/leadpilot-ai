LeadPilot AI | Intelligent Lead Management & Sales Automation Platform

# Project description draft

I built LeadPilot AI to explore a common small-business problem: inquiries arrive, context gets scattered, and the next follow-up becomes easy to miss.

The application brings lead capture, a sales pipeline, explainable qualification, message drafts, follow-up tasks, and database-backed analytics into one workspace.

Its 0–100 lead score shows every factor contribution and missing detail. The demo uses labeled local rules and templates, so it works without a paid API key. Private workspaces have an optional OpenAI-compatible extraction and drafting adapter. Every draft stays under human review.

Built with Next.js, React, TypeScript, FastAPI, SQLAlchemy, Alembic, and PostgreSQL configuration, with SQLite for a simple local demonstration. The engineering work includes tenant isolation, secure sessions, deterministic automation, scoped analytics, and automated backend/browser tests.

The demonstration uses a fictional agency and synthetic leads. It is a portfolio MVP, and I am not presenting customer conversion or revenue results.

The source, setup guide, and actual application screenshots are available on [GitHub](https://github.com/siddartttk/leadpilot-ai). The application currently runs locally; a hosted demo is still pending.
